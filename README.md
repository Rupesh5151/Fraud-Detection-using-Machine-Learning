# Fraud Detection using Machine Learning

An AI-powered fraud detection system built using Machine Learning algorithms to identify suspicious and fraudulent financial transactions. The project leverages data preprocessing, feature engineering, anomaly detection, and classification models to improve fraud prediction accuracy.

---

# Overview

Fraudulent financial transactions are a major challenge in digital payment systems. This project focuses on detecting fraudulent transactions using supervised machine learning models and data-driven analysis.

The system applies multiple classification algorithms including Logistic Regression, Random Forest, and XGBoost to identify anomalies and classify fraudulent payment activities with high accuracy.
